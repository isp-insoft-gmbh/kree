# `docs/specs/` — kree specifications

Two kinds of documents live here:

| Type | Files | Purpose |
|------|-------|---------|
| **Product spec** | [`spec.md`](spec.md) | The canonical "what to build" document. Read this first. Build-order steps in § 8 are the project's history; new additions live in implementation specs below. |
| **Implementation specs** | [`T1`–`T6`](.) | One per follow-up task agreed with the user *after* the original spec was complete. Each was reviewed (independent code-reviewer agent + advisor) before any code was written. |
| **Open items** | [`open-items.md`](open-items.md) | Deferred follow-ups — things the user has approved but that require external context (e.g. pushing to a real GitHub home) before they can land. |

External research that informs a spec but isn't itself a spec lives in
[`../winget-research.md`](../winget-research.md) — not here.
